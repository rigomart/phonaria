# Audio Gen

Generates phonetically accurate pronunciation audio for example words using ElevenLabs TTS with SSML phoneme tags.

## Features

- **Phonetic accuracy**: Uses CMU ARPA (ARPAbet) phoneme transcriptions wrapped in SSML
- **Word mappings**: Reads from `data/cmu-arpa-mappings.json` generated by helper-scripts
- **Batch processing**: Generates audio for all 189 unique example words
- **ElevenLabs integration**: Uses turbo v2 model with custom voice settings

## Data Flow

1. `helper-scripts` generates `data/cmu-arpa-mappings.json` with word → CMU ARPA mappings
2. `src/words.ts` loads mappings and provides word + IPA + CMU ARPA data
3. `src/word-inputs.ts` wraps words in SSML: `<speak><phoneme alphabet="cmu-arpabet" ph="...">word</phoneme></speak>`
4. `src/generate.ts` sends SSML to ElevenLabs for synthesis

## Setup

Add an ElevenLabs API key to `.env` in this package:
```ini
ELEVENLABS_API_KEY=your_key_here

# Optional overrides
# ELEVENLABS_VOICE_ID=21m00Tcm4TlvDq8ikWAM
# ELEVENLABS_MODEL_ID=eleven_turbo_v2
# WORDS_LIMIT=25  # cap for testing
```

## Generate Mappings (Required First)

Before generating audio, ensure word mappings exist:
```bash
bun --cwd packages/helper-scripts generate-word-mappings
```

This creates `packages/audio-gen/data/cmu-arpa-mappings.json` with:
- 189 unique words
- IPA phonemic transcriptions
- CMU ARPA tokens with stress digits

## Run

Generate audio files:
```bash
bun --cwd packages/audio-gen generate
```

Outputs land in `packages/audio-gen/output/*.mp3`

## Example SSML Output

```xml
<speak><phoneme alphabet="cmu-arpabet" ph="B AE1 K">back</phoneme></speak>
<speak><phoneme alphabet="cmu-arpabet" ph="AH0 K AW1 N T">account</phoneme></speak>
```
