# Self-hosted Lab fonts

Vendored Latin variable fonts so production builds never download from Google Fonts.

| File | Family | Source |
| --- | --- | --- |
| `sora-latin-wght-normal.woff2` | Sora (100–800) | [Fontsource Sora vf 5.2.8](https://fontsource.org/fonts/sora) |
| `noto-sans-latin-wght-normal.woff2` | Noto Sans (100–900) | [Fontsource Noto Sans vf 5.2.8](https://fontsource.org/fonts/noto-sans) |

Both families are licensed under the SIL Open Font License. See `sora-OFL.txt` and `noto-sans-OFL.txt`.
